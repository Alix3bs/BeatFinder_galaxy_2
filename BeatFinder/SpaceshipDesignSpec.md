# Spaceship Design Specification - Style C

## Overview
This document defines the visual design for the top-down mini spaceship used in the Safe mini-game. This specification can be used by designers or image generation tools to create the final asset.

## Design Style: Top-Down Mini Ship (Style C)

### Body Shape
- **Form**: Rounded triangle / teardrop shape
- **Orientation**: Pointing upward (nose at top)
- **Proportions**: Approximately 50-70 points wide, 70-100 points tall
- **Style**: Smooth, rounded edges (not sharp/angular)

### Outline / Border
- **Type**: Smooth neon outline
- **Gradient**: Cyan → Blue → Magenta (angular/conic gradient)
- **Width**: 2-3 points
- **Effect**: Glowing neon appearance

### Inner Body
- **Color**: Very dark gray / almost black (#0A0A0A or similar)
- **Finish**: Matte or slightly glossy
- **Fill**: Solid color

### Cockpit
- **Shape**: Small circle
- **Position**: Center-middle of the body
- **Size**: Approximately 12-16 points diameter
- **Color**: Soft white/blue glow
- **Effect**: Subtle glow/shadow with cyan tint
- **Opacity**: ~90% white with blue tint

### Engines
- **Quantity**: Two small engine circles
- **Position**: Back/bottom of the ship (one on each side)
- **Size**: Approximately 4-6 points diameter each
- **Spacing**: ~10 points apart (centered)
- **Color**: Cyan
- **Effect**: Soft blue thruster glow extending downward
- **Glow**: Cyan shadow/glow effect (~6-8 point radius)

### Overall Aesthetic
- **Theme**: Futuristic, neon, cyberpunk-inspired
- **Color Palette**: 
  - Primary: Cyan (#00FFFF)
  - Secondary: Blue (#0000FF)
  - Accent: Magenta/Pink (#FF00FF)
  - Base: Very dark gray/black
- **Glow Effects**: Soft, diffused glows throughout
- **Style**: Clean, minimalist, retro-futuristic

### Technical Notes
- Designed for use in a dark/black background environment
- Should be visible and readable at small sizes (mini-game context)
- Glow effects should be subtle but noticeable
- All measurements are approximate and can be adjusted for visual balance

### Usage Context
- Used in the Safe mini-game as the player-controlled ship
- Displayed in a top-down view
- Moves horizontally (left/right) while asteroids fall from above
- Needs to be clearly visible against black space background with stars
